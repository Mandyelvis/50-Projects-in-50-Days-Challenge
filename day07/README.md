# Day 07 — To-Do List

A responsive to-do list application built with HTML, CSS, and JavaScript as part of the JENGA TECH 50 Projects in 50 Days Challenge.

## Features

- Add new tasks
- Add tasks by pressing Enter
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks
- Dynamic task counter
- Empty-state message
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
