# Day 05 — Digital Clock

A responsive digital clock built with HTML, CSS, and JavaScript as part of the JENGA TECH 50 Projects in 50 Days Challenge.

## Features

* Displays the current time
* Updates every second
* 12-hour time format
* AM/PM indicator
* Displays the current date
* Responsive design
* Live time status indicator

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
day05/
├── README.md
├── index.html
├── style.css
└── script.js
```

## What I Learned

* Working with the JavaScript `Date` object
* Getting the current time and date
* Formatting hours, minutes, and seconds
* Using `setInterval()` to update content every second
* Manipulating HTML elements with JavaScript
* Creating responsive layouts with CSS
