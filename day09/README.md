# Day 09 — Quiz App

An interactive, responsive quiz application built with HTML, CSS, and JavaScript as part of the JENGA TECH 50 Projects in 50 Days Challenge.

## Features

- 10 multiple-choice questions
- Instant answer feedback
- Highlights correct and incorrect answers
- Automatic score tracking
- Progress bar
- Final results screen with performance feedback
- Restart quiz functionality
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

- Storing questions in JavaScript arrays and objects
- Dynamically creating HTML elements
- Handling click events
- Using conditional statements to check answers
- Tracking scores and quiz progress
- Updating the DOM
- Creating responsive layouts with CSS
