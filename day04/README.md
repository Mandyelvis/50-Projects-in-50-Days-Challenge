# Day 04 — Calculator

A simple and responsive calculator built with **HTML, CSS, and JavaScript** as part of the **JENGA TECH 50 Projects in 50 Days Challenge**.

## Features

* Addition, subtraction, multiplication, and division
* Percentage calculations
* Decimal numbers
* Clear button
* Delete button
* Responsive design
* Error handling for invalid calculations
* Clean dark-themed interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## What I Learned

* Creating a calculator interface with HTML
* Using CSS Grid for button layouts
* Handling button clicks with JavaScript
* Updating values dynamically in the display
* Performing calculations with JavaScript
* Handling invalid calculations with error handling
