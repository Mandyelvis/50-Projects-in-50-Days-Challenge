# Day 10 — Grade Calculator

A responsive grade calculator built with HTML, CSS, and JavaScript as part of the JENGA TECH 50 Projects in 50 Days Challenge.

## Features

- Enter a student's name and subject scores
- Validate scores between 0 and 100
- Calculate total score and average
- Assign grades from A to F
- Display performance remarks
- Show individual subject results
- Visual score progress bars
- Reset the calculator for another student
- Responsive design for desktop and mobile

## Grading System

| Average Score | Grade |
|---|---|
| 70–100 | A |
| 60–69.9 | B |
| 50–59.9 | C |
| 45–49.9 | D |
| 40–44.9 | E |
| Below 40 | F |
