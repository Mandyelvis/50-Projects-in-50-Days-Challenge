# Day 08 — Product Landing Page

A modern and responsive product landing page built with HTML, CSS, and JavaScript as part of the JENGA TECH 50 Projects in 50 Days Challenge.

## Features

- Responsive product landing page
- Navigation with smooth scrolling
- Hero section
- Product showcase
- Product features section
- Product specifications
- Pricing section
- Interactive Buy Now button
- Responsive mobile layout
- Hover effects and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript
