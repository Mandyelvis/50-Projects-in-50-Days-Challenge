# Day 06 — Counter App

A simple and responsive counter application built with HTML, CSS, and JavaScript as part of the JENGA TECH 50 Projects in 50 Days Challenge.

## Features

- Increase the counter
- Decrease the counter
- Reset the counter to zero
- Displays whether the counter is positive, negative, or zero
- Responsive design
- Interactive buttons with hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
